## 项目简介

本项目是一个基于 Web 的 Steam 创意工坊下载工具，专为 Wallpaper Engine 设计。它通过网页界面提供壁纸搜索和下载功能。

使用有一定的门槛：首先必须拥有 Steam 账号并已购买 Wallpaper Engine，其次需要有 NAS 之类的设备来运行 Docker。二创的目标是简化原本的使用流程，实现“NAS 下载，并推流给其他设备观看”。

## 核心特点

- **智能解析**：通过 API 抓取创意工坊页面，提取 FileID 和元数据（API 比网页版创意工坊资源更全，网页版有说明提示）。
- **自动打包规则**：
  - **场景 / 程序 / 网页类壁纸**：下载后压缩成zip。
  - **视频类壁纸**：直接提取原始视频文件（`.mp4` 等），下载后可直接播放。
- **零依赖构建**：自动编译成 Docker 镜像，开箱即用。

## 前置要求

1. **Docker**：能够运行 Docker 的设备。
2. **网络访问（按地区）**：是否需要代理取决于你的网络环境。若你所在地区可直连 Steam 创意工坊，则无需代理；若访问受限，再开启系统代理或配置代理环境变量（AI 提到 steamcmd 下载是直连的，不走代理。实际测试下来，浏览列表走代理，下载仍为直连，并未消耗代理流量）。
3. **SteamCMD**：程序启动时会自动尝试查找或下载 SteamCMD。如果失败，请检查网络或手动下载 SteamCMD 放入相应目录。

## 启动方式

1. **下载**本项目代码，获取 `wallpaper-webview` 文件夹。
2. **启动服务**：推荐使用 `docker compose` 启动（项目已包含 `docker-compose.yml`）。现在 Steam 账号、密码、API Key 都支持在网页界面直接输入，因此 `docker-compose.yml` 中与账号相关的环境变量可以留空或移除，仅需保留端口、数据卷等基础配置。配置完成后运行：
   ```bash
   docker compose up -d
   ```
3. **访问网页**：在浏览器打开 `http://你的设备IP:3090`，根据页面提示登录 Steam 账号（首次登录可能需要手机验证），并可在设置中填入 Steam API Key。

## 高级配置（可选）

以下环境变量可按需在 `docker-compose.yml` 或 `docker run` 中设置，但绝大多数已非必需，因为网页界面可直接处理。

| 环境变量 | 说明 | 默认值 | 是否必需 |
|----------|-------------|---------|----------|
| `PORT` | 服务端口 | `3090` | 否 |
| `HTTP_PROXY` | 代理地址 (如 `http://127.0.0.1:7890`) | 自动读取系统代理 | 否 |
| `STEAM_USERNAME` | Steam 账号（网页可登录，可留空） | - | 否 |
| `STEAM_PASSWORD` | Steam 密码（网页可登录，可留空） | - | 否 |
| `STEAM_API_KEY` | [Steam API Key](https://steamcommunity.com/dev/apikey)（网页可输入，可留空） | - | 否 |
| `STEAM_COUNTRY` | 商店地区代码 | - | 否 |
| `STEAM_LANG` | 语言设置 | `schinese` | 否 |

> 注意：`HTTP_PROXY` 主要用于浏览列表时的代理，下载仍为直连。如果已在系统层面配置了代理，此处一般无需额外设置。

- 新手制作，完全由 AI 修改，好在 Docker 最终能正常运行。
- 在 FN OS 下跑成功了，只测试了账号登录。（SteamCMD 第一次登录需要手机验证，登录信息会保存在 `/root/Steam` 中，后续一般无需再次验证）
- 壁纸资源终于完整了，使用了 API，走 API 的网址。测试时不挂代理也能偶尔连上，但稳妥起见还是建议挂上代理，好在下载本身是直连，影响不大。
- 这个项目原本只是为了简化自己的流程：从以前的“电脑订阅 → 右键文件管理 → 复制到 NAS → 取消订阅 → NAS 推流给手机”，简化为现在的“NAS 下载 → 推流给手机”，流程大幅简化。
- 增加了一些功能：登录状态固化（重启不失效）、下载队列（原版多个订阅同时下载容易出问题，队列化后会依次下载，并显示下载进度和容器的实时网速）、查看作者的其他作品（方便寻找更多壁纸）、优化了底部分页栏（支持跳转）。
- 非视频类壁纸打包成 zip，主要是为了方便下载，下载到本地解压后，配合 [RePKG](https://github.com/notscuffed/repkg) 工具，通过命令行可以批量提取文件夹（因为它是 exe 工具，不方便集成进 Docker）。提取后可以找到原图，很多只支持静态壁纸的地方就能用了。
- 自己用时遇到Bug会时不时修一修，修了评论不显示、windows中英文图标问题等bug。加了Steamcommunity_302，可以直连steam社区，不用挂梯子了，不需要的可以删掉对应文件夹和docker-compose中的配置（Steamcommunity_302文件夹的挂载和command命令）。

### 一、筛选与排序
- 类型选择、年龄评级下拉改为多选
- 删除已停用的"应用"类型选项
- 排序新增"评分最高"并设为默认
- 优化切换加载代码以及筛选数据功能

### 二、状态持久化
- 筛选、搜索、页码、视图模式、主题等状态写入 URL，刷新不丢失
- 部分界面记忆功能，如本地图库，滑动后关闭打开会记得之前的位置

### 三、本地下载库
- 新增本地图库功能，记录已下载壁纸
- 本地图库元数据通过下载文件名末尾的 ID 识别源，自动获取封面等信息
- 本地图库和下载队列显示预览图，点击预览图可播放，点击名字展开壁纸详情
- 非视频类壁纸统一打包为 ZIP 下载

### 四、播放功能
- 新增视频播放器组件，视频播放采用视频流方式（有点占内存，会自动回收其实影响不大，可给 Docker 设置内存上限，自己测试下来限制到 100M 内存以下都感觉没啥影响）
- 布局：进度条（底部）、播放/暂停+时间（左下）、播放速度+音量+全屏（右下）、关闭（右上）、下载（左上）
- 播放器按钮 3 秒无操作自动隐藏
- 左右方向键支持快进/快退 5 秒
- 音量控制改为竖排滑块，播放速度选择改为竖条选择框（0.5x / 0.75x / 1x / 1.5x / 2x）
- 电脑端：单击暂停/播放，双击全屏
- 手机端：单击显示/隐藏按钮，双击暂停/播放，返回键等同于关闭按钮

### 五、外部播放方案
- 新增外部播放方式配置，支持添加多个播放方案
- 高度自定义，可自行编辑，有 `{url}`、`{name}` 两个转义符表示网页链接（视频流链接）和文件名
   - 可用 `potplayer://{url}`、`nplayer-{url}`、`https://openlist:5244/folder/{name}` 等实现转跳播放
- 可设置默认播放方式（内置播放器为默认选项之一）
- 鼠标右键（手机长按）播放按钮弹出所有播放方案选择列表
- 支持 `<cmd>...</cmd>` 动态解析，支持嵌套解析
   - 飞牛影视转跳成功，自己去浏览器里抓包，token 是手动给的，最后用脚本整理成 id
   - `https://fnos/<cmd>解析id的脚本<cmd>解析token的脚本</cmd>{name}整理id的脚本</cmd>`
   - 飞牛 API 未开放，也不能明文登入，自动获取 token 较麻烦，干脆手动提供，失效后需重新给；Jellyfin 等开放 API 的应更易实现

### 六、下载队列恢复
- 加入队列时在 Steam 临时目录创建对应 ID 的空文件夹
- 服务启动时扫描文件夹，识别 ID 加入下载队列
   - 总之不怕突然断电/重启导致队列丢失

### 七、UI/交互优化
- 删除中英切换，统一中文界面（如有需要，请自行翻译源码）
- 浏览界面/壁纸详情页检测本地库，已下载壁纸将订阅键替换为播放/已下载状态
- 缩略图左上角增加类型标识（视频/非视频）
- 重新设计 Steam API 按钮
