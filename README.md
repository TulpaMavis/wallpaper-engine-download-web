## 项目简介

本项目是一个基于 Web 的 Steam 创意工坊下载工具，专为 Wallpaper Engine 设计。它通过网页界面提供壁纸搜索和下载功能。

使用有一定的门槛：首先必须拥有 Steam 账号并已购买 Wallpaper Engine，其次需要有 NAS 之类的设备来运行 Docker。二创的目标是简化原本的使用流程，实现“NAS 下载，并推流给其他设备观看”。

## 核心特点

- **智能解析**：通过 API 抓取创意工坊页面，提取 FileID 和元数据（API 比网页版创意工坊资源更全，网页版有说明提示）。
- **自动打包规则**：
  - **场景 / 程序 / 网页类壁纸**：下载后整个文件夹会被移入 `downloads` 文件夹中。
  - **视频类壁纸**：直接提取原始视频文件（`.mp4` 等），下载后可直接播放。
- **零依赖构建**：自动编译成 Docker 镜像，开箱即用。

## 前置要求

1. **Docker**：能够运行 Docker 的设备。
2. **网络访问（按地区）**：是否需要代理取决于你的网络环境。若你所在地区可直连 Steam 创意工坊，则无需代理；若访问受限，再开启系统代理或配置代理环境变量（AI 提到 steamcmd 下载是直连的，不走代理。实际测试下来，浏览列表走代理，下载仍为直连，并未消耗代理流量）。
3. **SteamCMD**：程序启动时会自动尝试查找或下载 SteamCMD。如果失败，请检查网络或手动下载 SteamCMD 放入相应目录。

## 启动方式

1. **下载**本项目代码，获取 `wallpaper-webview` 文件夹。
2. **启动服务**：推荐使用 `docker compose` 启动（项目已包含 `docker-compose.yml`）。现在 Steam 账号、密码、API Key 都支持在网页界面直接输入，因此 `docker-compose.yml` 中与账号相关的环境变量可以留空或移除，仅需保留端口、数据卷等基础配置。配置完成后运行：
   ```bash
   docker compose up -d
   ```
3. **访问网页**：在浏览器打开 `http://你的设备IP:3090`，根据页面提示登录 Steam 账号（首次登录可能需要手机验证），并可在设置中填入 Steam API Key。

## 高级配置（可选）

以下环境变量可按需在 `docker-compose.yml` 或 `docker run` 中设置，但绝大多数已非必需，因为网页界面可直接处理。

| 环境变量 | 说明 | 默认值 | 是否必需 |
|----------|-------------|---------|----------|
| `PORT` | 服务端口 | `3090` | 否 |
| `HTTP_PROXY` | 代理地址 (如 `http://127.0.0.1:7890`) | 自动读取系统代理 | 否 |
| `STEAM_USERNAME` | Steam 账号（网页可登录，可留空） | - | 否 |
| `STEAM_PASSWORD` | Steam 密码（网页可登录，可留空） | - | 否 |
| `STEAM_API_KEY` | [Steam API Key](https://steamcommunity.com/dev/apikey)（网页可输入，可留空） | - | 否 |
| `STEAM_COUNTRY` | 商店地区代码 | - | 否 |
| `STEAM_LANG` | 语言设置 | `schinese` | 否 |

> 注意：`HTTP_PROXY` 主要用于浏览列表时的代理，下载仍为直连。如果已在系统层面配置了代理，此处一般无需额外设置。
